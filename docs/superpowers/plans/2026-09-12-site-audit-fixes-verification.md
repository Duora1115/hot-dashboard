
### 复验中另外发现的一个问题（不在原 22 条内，且为存量缺陷）

在 2026-07-06 与其它页面之间来回 SPA 导航时，仪表盘的统计数字会漂移（实测 1,148 → 0 → 946）。根因是 `src/store/useStore.ts` 的 `refreshData()`：它只比较 `latest.t > last.t`，**不校验 `latest` 是否属于当前选中的日期**，满足条件时执行 `snaps[snaps.length - 1] = latest` —— 把「今天」的快照塞进了历史某天的快照数组，聚合值随即失真。

可达性：线上选中一个历史日期、停在「实时」模式，App.tsx 的定时刷新就会把今天的快照拼进那天的视图。

**这是存量缺陷，与本分支无关**（`git diff main..HEAD -- src/store/useStore.ts | grep refreshData` 无输出，`App.tsx` 也没被本分支改过），因此未纳入本轮修复，单独报给用户决定。修法是给 `refreshData` 加一行日期守卫：`if (latest.t.slice(0,10) !== get().currentDate) return;`
