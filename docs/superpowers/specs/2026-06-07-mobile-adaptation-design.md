# 移动端页面适配设计

**日期**: 2026-06-07
**作者**: Claude Code
**状态**: 已批准

## 概述

为飞书群热点看板添加移动端页面，用户可通过右上角按钮在桌面版和移动版之间切换，同一 URL 内响应式切换，不跳转路由。

## 架构

### 方案选择
- **单文件 HTML**：保持 `index.html` 不拆分，通过 CSS 类切换控制视图模式
- **CSS 三层**：
  1. Base — 通用变量、重置、基础组件（桌面/移动共享）
  2. Desktop — 当前样式包装在 `:root:not(.mobile-mode)` 下
  3. Mobile — `:root.mobile-mode` 下的覆盖样式
- **JS 逻辑不变**：数据获取完全复用，仅渲染层根据模式分发

### 切换机制
- 右上角悬浮按钮（📱 / 🖥 图标）
- 点击在 `<html>` 上切换 `mobile-mode` 类
- `localStorage.viewMode` 持久化用户选择
- 页面加载时 `detectMobile()`：`window.innerWidth <= 768` 默认移动端，可覆盖

## 组件与布局

### 移动端（`mobile-mode`）

| 区域 | 桌面版 | 移动端 |
|------|--------|--------|
| 标题栏 | 居中，完整字号 | 缩小，控制按钮改为图标 |
| 模式切换 | 独立 Tab | 合并为小开关 |
| 日期选择 | 居中 select + 按钮 | select 全宽，按钮隐藏 |
| Tab 栏 | 居中，固定宽度 | 横向滚动（overflow-x: auto）|
| 统计栏 | 多列居中 | 2 行 3 列或横向滚动 |
| 时间轴 | 标准宽度 | 全宽，标签缩小 |
| 股票表 | 9 列表格 | 卡片列表（排名、代码、名称、热度条、多空、板块标签）|
| 板块 Grid | 多列 Grid | 单列，卡片全宽 |
| 情绪面板 | 居中仪表 + 表格 | 仪表居中放大，表格折叠为可展开卡片 |
| 信号面板 | 多列 Grid + 表格 | 信号卡片 2 列，表格折叠 |
| Modal 弹窗 | 640px 居中 | 95vw 几乎全屏 |

## 数据流

- 数据获取逻辑不变，`app.js` 的 `fetch()` 调用完全复用
- `render()` 函数检测 `mobile-mode`，分发到 `renderXxxMobile()` 或现有 `renderXxx()`
- 模式切换不重新请求数据，只重新渲染当前面板（数据已在内存中）

## 错误处理

- 无新增错误路径，所有 API 错误处理复用现有逻辑
- 移动端无新增网络请求

## 测试

2. 自动识别移动端，布局正确
3. 切换桌面版按钮正常工作
4. 各 Tab 在移动端正常显示
5. 板块卡片点击弹窗正常
6. 时间轴拖动正常
7. 刷新后模式选择被记住

## 不做的

- 不做 PWA / 离线 / 安装提示
- 不做触摸手势（滑动/缩放）
- 不做独立路由（`/mobile`）
